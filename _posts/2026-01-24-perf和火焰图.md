`perf` 是 `Linux` 内核提供的性能分析工具，对于分析热点代码，进程运行状态十分有用。下面介绍`perf` 的常见用法。

## perf top

当系统遇到问题，比如说`cpu`占用率很高，可以利用`perf top` 命令分析是哪个热点函数导致`cpu`占用过高。以此demo为例子：
```c
#include <stdio.h>

void test_fun(){
    volatile unsigned long long i = 0;
    while (1) {
        i++;
    }
}

int main(void)
{
    test_fun();
    return 0;
}
```

运行此demo 通过`top`命令观察，可以看到该进程`cpu`占用很高。
![](/assets/image/Pasted%20image%2020260124140113.png)

执行`perf top` 命令可以清楚的看到是`a.out` 代码中`test_fun` 使用了最多的`cpu`。
![](/assets/image/Pasted%20image%2020260124140228.png)
## perf stat

采集具体的事件，分析进程运行状态。
常见的用法如下，具体的事件名可以通过`perf list`获取。

```shell
#指定pid
perf stat -p <PID>

#指定时间
perf stat -p <PID> sleep 10

#实时打印 1s 一次
perf stat -I 1000 -p <PID>

# 指定事件
perf stat -e cycles,instructions,LLC-load-misses -p 1234 sleep 5
perf stat -e cache-misses,LLC-load-misses,LLC-loads,LLC-store-misses,LLC-stores,mem_load_uops_retired.l2_hit,mem_load_uops_retired.l2_miss,cycles,instructions -p 388 sleep 5

#查看cpu迁移 以及上下文切换
./perf stat -e cpu-migrations,context-switches -p 388 sleep 5


```


## perf record 和火焰图

`perf record` 可以记录进程运行的调用栈，可以通过`FlameGraph` 进行火焰图 图形化，分析具体的热点代码。以如下代码为例子，编译的时候带上`-g`选项
```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
void fun1() {
	int i = 0, j = 0;
	for (i = 0; i < 100000; i++) {
	for (j = 0; j < 10000; j++) {
	}
	}
}
void fun4() {
	int i = 0, j = 0;
	for (i = 0; i < 100000; i++) {
	for (j = 0; j < 100000; j++) {
	}
	}
}
int main() {
	int i = 0;
	fun1();
	sleep(2);
	fun4();
	return 0;
}
```


```shell
gcc hello.c -g  

#运行程序收集数据
perf record -F 99  --call-graph dwarf  ./a.out
#或者绑定pid   -F 表示采样频率
perf record -F 1000 -p $p1 --call-graph dwarf  -- sleep 25


#解析perf record 数据
perf script --header > out.stacks

#下载火焰图程序生成火焰图，生成out.svg文件，可以用浏览器打开。
git clone https://github.com/brendangregg/FlameGraph.git
./stackcollapse-perf.pl < ../out.stacks | ./flamegraph.pl --hash > ../out.svg

```
